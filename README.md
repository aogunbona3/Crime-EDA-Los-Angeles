# Los Angeles Crime Data – Exploratory Data Analysis (EDA)

## Overview
This project presents a data-driven analysis of crime in Los Angeles from 2020 to 2024. It identifies patterns across time and neighborhoods using Python and visualization libraries.

## Tools Used
- Python (pandas, seaborn, matplotlib)
- Jupyter Notebook
- HTML export for polished report presentation

## Objectives
- Analyze crime frequency over time
- Identify seasonal or geographic patterns
- Visualize top crime categories
- Explore correlation between variables

## Key Visuals
- Bar charts showing top crime categories
- Monthly crime trend line plots
- Heatmap of crime correlations

## Key Insights
- **Theft** remains the most common crime throughout the years.
- **Crime incidents peaked in colder months**, particularly during spring and winter.
- **Downtown LA and South LA** showed consistently high crime volumes.
- Some decline in total crimes observed during peak COVID-19 lockdowns.
